## 03. Projetos em destaque

### NEXCORE

**Windows Utility | System Tools | Software Development**

O **NEXCORE** é um projeto de software para Windows desenvolvido com foco na criação e evolução de ferramentas e funcionalidades para o sistema.

O projeto teve como uma de suas referências o software open source **ResetExplode**, desenvolvido por GustavoReset.

A partir de algumas funções disponibilizadas no projeto original, expandi a aplicação com novas funcionalidades, melhorias e implementações próprias.

O desenvolvimento representa minha experiência prática com análise de software, reutilização de código open source e evolução de aplicações.
